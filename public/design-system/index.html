Design System

Colours, type and atoms for ApnaSafar. Nothing here is wired into the app yet.

Typefaces

Two typefaces doing three jobs. Each name below is set in its own font. Season Mix is a trial font — a web licence must be bought from Sunday Fonts before this site goes live, and the files are kept out of the repository until then.

FontRoleLicenceCharacter
Season Mix Display & accents Trial — licence needed Elegant fashion serif. Sets every heading; its italic is the accent face.
Season Mix Italic Accent words Trial — licence needed The lift on words like passion. Same family, no extra font.
SF Pro All body text Apple system font Comes from the device. Segoe UI on Windows, Roboto on Android.

Grid

Twelve columns, because twelve divides by 2, 3, 4 and 6 — so a row holds halves, thirds, quarters or sixths with nothing left over. Put .grid on a row and .col-6 on a child. Narrow the window to watch it fold.

Spacing

Every gap on the site is a multiple of 4px. The number in the token name is the multiplier, so --space-6 is 6 × 4px = 24px. There is no 28, 36 or 56 — if a design asks for 30, the answer is 32.

--space-0-5  2px  ·  optical nudge
--space-1  4px  ·  icon to label
--space-2  8px  ·  label to input
--space-3  12px  ·  button padding
--space-4  16px  ·  the default inset
--space-5  20px  ·  roomier card
--space-6  24px  ·  grid gutter
--space-8  32px  ·  group to group
--space-10  40px  ·  heading to content
--space-12  48px  ·  grid row gap
--space-16  64px  ·  tight section
--space-20  80px  ·  section
--space-24  96px  ·  page rhythm
--space-32  128px  ·  the big quiet gap

One scale, used directly — a card writes padding: var(--space-4), not a card-padding token that points here. The only distances that change with screen width are the grid gutter, the page gutter and the two section gaps, which live in styles/03-grid.css. Full rules in docs/04-spacing.md.
