## How the pages are written

Each page leads with the thing you came for — the swatches, the specimens,
the scale. Reference detail sits below that, and only where it changes a
decision. Pages are not all the same length: Color carries more rules because
more can go wrong with it.

## The rule that holds it together

```text
PRIMITIVE  →  SEMANTIC  →  COMPONENT
```

Components read semantic tokens only. They never reach past that layer to a
primitive. This single constraint is what makes theming, rebranding and
accessibility fixes possible without touching component code.

## Non-negotiables

- **Nothing is hand-transcribed.** Scales are generated; the docs read the
  generated output. A value cannot change without its documentation changing.
- **Accessibility is computed, not claimed.** Contrast tables come from a
  script run against the real tokens.
- **Failures are named, not quietly adjusted.** If something does not meet
  the bar, the page says so and says why.
